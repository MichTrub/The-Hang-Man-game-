# The-Hang-Man-game-
Game where you should guess letter of the word and in fixed amount of tries you should guess the word
Hangman Game
A command-line Hangman game written in Python where the player guesses a randomly selected word one letter at a time.

Features:
Random word selection
Input validation
Tracks guessed letters
ASCII hangman display
Win and lose conditions

What I practiced:
Loops
Lists
Strings
User input handling
Random number generation

In order to run:
python main.py
